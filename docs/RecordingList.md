# Recordings wanted (short version)

14 short files, about 20 minutes of playing in all. No click, no counting bars, nothing to learn: each file is
one simple thing. I find where every note starts in the audio myself, so all I need is that you play what the
file says, in that order.

## Setup (once)

- **Dry DI only**: guitar or bass straight into the interface. No amp sim, pedals or plugins.
- Input gain as you'd set it to play live; never clipping.
- **WAV, 48 kHz, 24-bit, mono**. Please not MP3.
- **Tune to A = 440** before each file.
  - Guitar: 7-string, drop A: **A E A D G B E** (low to high).
  - Bass: 5-string, drop A: **A E A D G**.
- Leave about a second of silence at the start of each file and between the parts of a file.
- If you mess up, just start that file again: they're all short.

"Low A string" means the 7th string on the guitar and the 5th on the bass.

## Guitar (8 files)

| File | What to play |
|---|---|
| `gtr-noise.wav` | 20 seconds of **not playing**: guitar plugged in, volume up, hands resting on the strings. |
| `gtr-frets.wav` | **Every string, open to 12th fret, one note at a time.** Low A string first, then the next string up, ending on the high E. Slowly: pick, let it ring about a second, mute, next. Neck pickup. |
| `gtr-frets-bridge.wav` | The same as `gtr-frets.wav`, but only the **three lowest strings**, on the bridge pickup. |
| `gtr-sustain.wav` | Pick a note and **let it ring until it's completely gone**, then the next. Four notes: open low A, open low E, 5th fret G string, 12th fret high E. |
| `gtr-fast.wav` | **Fast repeated picking**, about 5 seconds each, as fast as you comfortably can: open low A, then open low A palm-muted, then 7th fret G string. |
| `gtr-legato.wav` | On the G string, **each thing four times**: hammer-on 5 to 7; pull-off 7 to 5; slide 5 to 7; bend the 7th fret up a whole step and back. Then hold the 7th fret with vibrato for a few seconds. |
| `gtr-chords.wav` | **Strum each chord once, let it ring about 2 seconds, mute.** In this order: E, A, D, G, C, Em, Am, Dm, F (barre), Bm (barre). Low A string not played. |
| `gtr-low-chords.wav` | **Power chords on the three lowest strings** (one finger across them): open, 3rd fret, 5th fret, 7th fret. Each one strummed once and left ringing about 2 seconds, then the same four chugged palm-muted for about 2 seconds each. |

## Bass (6 files)

Fingerstyle unless it says otherwise.

| File | What to play |
|---|---|
| `bass-noise.wav` | 20 seconds of **not playing**: bass plugged in, volume up, hands resting on the strings. |
| `bass-frets.wav` | **Every string, open to 12th fret, one note at a time.** Low A string first, ending on the G string. Slowly: pick, let it ring about a second, mute, next. |
| `bass-frets-pick.wav` | The same as `bass-frets.wav`, but with a **pick** and only the **two lowest strings**. |
| `bass-sustain.wav` | **Let each note ring until it's completely gone**: open low A, then open E. |
| `bass-fast.wav` | **Fast repeated notes**, about 5 seconds each: open low A, then open E, then 5th fret on the low A string. |
| `bass-legato.wav` | On the low A string, **each thing four times**: hammer-on 3 to 5; pull-off 5 to 3; slide 5 to 7. |

## Optional, if you feel like it

- `gtr-play.wav` and `bass-play.wav`: a minute or two of whatever you normally play. No rules. A sentence on
  what it was (riff, song, chords) helps.

That's all. Send them in a folder or a zip, with a note if something's different from the above (a different
order, a skipped part, which guitar and bass).
